# MyLibrary su invito (v94) — piano di lavoro

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** l'app si apre solo dopo l'accesso e solo per gli invitati di Diego (e per Diego); le regole di Firestore lo impongono dal server; Diego gestisce l'elenco da «Invitati»; «Esci» toglie i libri dal dispositivo.

**Architecture:** `firestore.rules` nel repository, provate con l'emulatore ufficiale (jar Java, richieste REST con token non firmati); in `cloud.js` il controllo dell'invito prima della sincronizzazione e le funzioni per l'elenco; in `app.js` la «porta» (schermata d'accesso, schermata «non invitato»), «Esci» che pulisce, scheda «Invitati».

**Tech Stack:** JS senza build, Firebase compat 10.14.1, emulatore Firestore (Java 21), Playwright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-15-invitati-design.md`
