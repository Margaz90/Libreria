# «Novità per te» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sezione «Novità per te» con proposte motivate e uscite dei propri autori, aggiornata una volta a settimana nell'app, con pop-up per le uscite degli autori letti.

**Architecture:** Funzioni pure in un tratto `// <regole>` di `app.js` (gusti, scarti, motivazioni, voto); un giro settimanale in sottofondo (`giroNovita`) che interroga Apple Books Italia, Google Books e Open Library con le funzioni di ricerca esistenti, estese con voti e date; memoria in `localStorage` `libreria-novita`; una nuova vista `state.view === "novita"` al posto di «Cerca» nella barra in basso.

**Tech Stack:** JavaScript senza build (`app.js`, `style.css`, `index.html`), test Playwright (`test/*.mjs`) e Node (`test/regole.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-07-novita-design.md`

## Global Constraints

- Lingua di tutti i testi: italiano; copy esatta dalla spec.
- Nessuna libreria nuova; peso aggiunto circa 12–15 KB.
- Ogni libro si salva solo con `salvaLibro` (v77); nuovi libri: stato `desiderato`.
- Funzioni pure dentro `// <regole>` … `// </regole>` (v79): niente `document`, `state.`, `localStorage`, `indexedDB`, `navigator.`.
- Rete: `fetchT` (20 s), pause di Google (`state.googleDown`) e Wikidata (`fonti.inPausa`), 600 ms tra le richieste.
- Voto mostrato solo con almeno 20 voti, con il nome della fonte.
- Novità mai nel cloud né nei backup; chiave `libreria-novita`.
- Bersagli al tocco ≥ 44 px; colori solo dai token esistenti; 390×844 e 1366×860, chiaro e scuro, niente scorrimento laterale.
- `VERSION` in `sw.js` → v84; `docs/funzioni.md`, `docs/storia.md`, `CLAUDE.md`, `docs/strumenti.md` aggiornati.

## Review Focus

- Libreria con pochi Letti o nessun voto → messaggio «Dai qualche voto…», nessun giro inutile verso le fonti (test in Task 3).
- Fonte che restituisce date non valide o voti fuori 0–5 → risultato scartato, nessun errore in console (test in Task 1).
- Libro aggiunto dal cloud mentre la sezione è aperta → sparisce dalle novità al ridisegno (test in Task 3).
- App aperta per ore oltre i 7 giorni → nessun giro a metà uso, solo alla prossima apertura (test in Task 2).
- Pop-up con una scheda già aperta (es. accesso via link) → non si sovrappone: aspetta l'apertura successiva (test in Task 4).
